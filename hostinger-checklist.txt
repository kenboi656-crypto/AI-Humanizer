🚀 DEPLOYMENT PROCESS
═════════════════════════════════════════════════════════════════════

□ Access Hostinger
  □ Log into https://hpanel.hostinger.com/
  □ Select correct domain
  □ Note down SSH credentials

□ SSH & Initial Setup
  □ SSH into server
  □ Navigate to public_html (or domain directory)
  □ Clone GitHub repository
  □ Verify Node.js version: node -v (should be 18+)
  □ Verify npm version: npm -v (should be 9+)

□ Install & Configure
  □ Run: npm install
  □ Copy .env.example to .env
  □ Edit .env with GEMINI_API_KEY
  □ Set APP_URL to your domain (https://your-domain.com)
  □ Verify all environment variables are set

□ Build Application
  □ Run: npm run build
  □ Build completes without errors
  □ Check dist/ folder exists
  □ Check server.js file created

□ Configure Reverse Proxy
  □ Verify .htaccess in public_html root
  □ Verify ProxyPassReverse configured for port 3000
  □ Check .htaccess not hiding files

□ SSL & HTTPS
  □ SSL certificate installed (Hostinger auto-provides)
  □ HTTPS accessible from browser
  □ HTTP redirects to HTTPS
  □ Certificate shows as valid (no warnings)

□ Start Application
  □ Option A - Via hPanel:
    □ Go to Applications
    □ Create/Start Node.js application
    □ Set startup file: server.js
    □ Set port: 3000
    □ Status shows: Running (green)
  □ Option B - Via SSH/PM2:
    □ Run: npm install -g pm2
    □ Run: pm2 start server.js --name "ai-humanizer"
    □ Run: pm2 startup
    □ Run: pm2 save
    □ Verify status: pm2 status
